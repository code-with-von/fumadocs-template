In this section, it's possible to be seen the list with some of the **Fumadocs** components that can be used for documenting this project.

For information about other components that may be used but not listed in this document, check [Fumadocs documentation](https://www.fumadocs.dev/docs).

<Callout type='warning' title='Note'>
To avoid problems with those components, avoid updating any packages inside our `package.json` as this project was built with specific versions for some libraries, as using everything into the latest version available was causing compatibility problems!
</Callout>

### 1. Components list

1. **Codeblocks** - a better implementation of the default codeblock component, expanding it to with some other features which can be used while documenting projects
1. **Diagrams** - the inclusion of **Mermaid** diagrams to this template, with the possibility of expanding the templates with customization  or even adding icons into those
1. **Images** - an improvement of the default way of displaying images on your application, making them expandable
1. **Math Equations** - documenting needs math equations? We got you covered!
1. **Tables with types** - a component used to display tables, while describing the expected data type of the value for the referenced field, mainly used to describe functions parameters
1. **Story** - mainly used to represent interactive components, so the user can preview how the component should behave over changes on it's defined properties
1. **Open Api** - uses Open API (json or yaml) syntax to document API endpoints properly

Each one of those have their own dedicated page with explanation and examples of use.

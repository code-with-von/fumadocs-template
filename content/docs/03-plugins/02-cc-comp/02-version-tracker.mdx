The version tracker component is a small and simple to use component, created to help the **end-users** to understand and track important aspects as:

- Changelogs
- Different version releases
- Different reviews
- Any other aspect of the application documented that relies on version control


### 1. Version Tracker props

The Version tracking component uses two simple properties, as listed below:

<TypeTable
  type={{
    isCurrent: {
      description: 'If the referenced version is the current one or not',

    children: {

    }
  }}
/>

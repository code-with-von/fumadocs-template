This widget was created specifically thinking on Spotify users. It displays on the application the current Spotify song currently being listened to, at the current time, while adding also a button that will redirect users to their own Spotify accounts to listen with you. It's an implementation of what most developers use on their Github Profiles (feel free to check me using it on my [profile](https://github.com/code-with-von)) to be used in this application inside any **JSX / TSX** files.


<Callout type='error' title='IMPORTANT'>
  1. This component  uses the [Spotify Github profile by **kittinanx**](https://spotify-github-profile.kittinanx.com) API.
</Callout>


### 1. Connecting your account

For this component to work properly, it's important that:
- [x] The user has an active **Spotify account**
- [x] Connects their account to the [Spotify Github profile by **kittinanx**](https://spotify-github-profile.kittinanx.com) API
- [x] Provide the generated link after applying their desired customizations as an **environmental variable** in the project using either by using:
  >  - Infisical; or
  >  - **.env** / **.env.local** file
  > ```ini title='.env / .env.local'
  > # --------------------------------------------------------------------------------------------------
  > # Posthog settings
  > # Those values should be obtained from Posthog dashboard in case you wish to work with your own Posthog account, and not the shared one provided by Infisical
  > # --------------------------------------------------------------------------------------------------
  > NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN=
  > NEXT_PUBLIC_POSTHOG_HOST=
  >
  > # -------------------------------------------------------------------------------------------------- #[!code focus]
  > # Spotify settings #[!code focus]
  > # This is the URL generated by https://spotify-github-profile.kittinanx.com after you successfully connect your account to this application #[!code focus]
  > # -------------------------------------------------------------------------------------------------- #[!code focus]
  > NEXT_PUBLIC_SPOTIFY_URL=your_generated_url_here  #[!code focus]
  > ```
- [x] Edit the main component code found at **/components/custom/SpotifyWidget.jsx** to make adjustments to the image customization applied in the API, **if needed**

<Callout type='error' title='IMPORTANT'>
  1. The referenced api returns an image based on the selections done made by the user when connecting their **Spotify** to this api, so it's important to node that adjustments on the general style of the component that renders the widget were made to fit the specific image displayed in this page!
</Callout>

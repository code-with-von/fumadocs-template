In this section, we provide the necessary information needed to use some other custom components created not using **Fumadocs** and their related **3rd party libraries**, but personal creations done by **me, von Schappler**.

### 1. Components list

1. **Animated terminal** - an adaptation of the **animated terminal** created by the  **Aceternity** team, with some extra features added to it
1. **Version Tracker** - A small bu useful component used to visually display version numbers with a subtle pulsing animation
1. **Spotify Widget** - a component that displays the current song played on Spotify

Each one of those have their own dedicated page with explanation and examples of use.

Regardless of how many files your final project needs, here there will be a list of the files that could be changed safely for you, **as the user**, change without breaking how this template works.

### 1. Files/Folder List

The list of files below represent the list of files that should be changed for you to use this template as you see fit.

<Callout type='error' title='IMPORTANT'>
  The folder structure below lists files a **generic** folder structure with the files you **can be changed** (and **should be changed**) based on your *project requirements*. 
  
  - **This list is only a reference created on the actual project, but not exhaustive or static**, which means you can:
    - add files if you need
    - remove files if you don't need them
    - rename files if you want to
    - change/edit the code when necessary

  Just **remember** that:
  1. changes on the files listed here, should be done based on the required knowledge to change them
  1. files not listed here **can still be changed**, but any changes done are **at your own risk** and **knowledge-based** on the tech-stack required for using this template
  
  <Callout type='warning' title='ATTENTION'>
    Files listed below are relative to the root level of the project you are creating from this template and names may not match exactly the ones you will find in your project when cloned.

    - `...` means that other files or folders exist under this concept and, regardless of the reason they exist, they were not listed to avoid overflowing information
  </Callout>

</Callout>

The Github files with importance shared in this project are inside the folder **.github/workflows** and they are responsible for the **CI/CD** side of the application, in case you wish to make use of them.

Currently, the provided template provide two main files:
1. **checks.yml**
    - uses **Github Actions** to check if the codebase created can be safely deployed, based on default checks I use on my daily base
1. **deploy.yml**
    - uses **Github Actions** to deploy the project based on the given configurations

<Callout title='NOTE'>
You are free to add new files or edit the existing ones to your own needs, **at your own risk**!
</Callout>

No more details will be provide for those files - the files provided fits the project, considering all requirements on [this page](/docs/dev-only#2-skills-needed-to-use-this-template) are fulfilled by the one using this template, as those files were created based on them.

<Callout title='NOTE'>
    In case you don't need those files or want to make your own, feel free to delete the ones existing, or adding the files which are already part of your **CI/CD** flows.
</Callout>

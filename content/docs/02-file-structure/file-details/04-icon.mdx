As **Fumadocs** is a documentation framework built on top of **Nextjs**, adding **favicons** to the application works based on the same concept as it's describe into [Next.js official documentation](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/app-icons).

So this file, **app/icon.png** is the file that will be displayed as the **favicon** of your documentation application and the file provided in this specific path **HAS TO** be replaced by the ones **using this template**.

### 1. How to create the **icon.png** file

That is hard answer to provide, as this depends on a lot of variables.

But the way **I** created that was using image editor applications and exported the file as **\icon.png** file and saved the file where it needs to be placed by any **Nextjs** based application.

The most important aspects regarding the **favicon** file are:
- You need to make your own **favicon / icon file** by any means you find suitable and achievable by you
- Never use my own **icon.png** on your projects, as that is a *Copyrighted file** on any of your projects created based on this template, otherwise you can be **LEGALLY sued for impersonating my person**

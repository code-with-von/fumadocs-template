Considering the nature of how **Fumadocs** was built (on top of **NextJs**), it's then expected that any internal application broken routes would redirect automatically to a "Not Found" page.

This page is rendered by the **not-found.tsx** file found at the root level of the **app** folder. **It's possible** to create as many **not-found.tsx / not-found.jsx** files as needed according to [NextJs official documentation](https://nextjs.org/docs/app/api-reference/file-conventions/not-found).

In this template, only the **not-found** file mentioned above was created, and the actual codebase of the file is part of what **I** use on my documentation templates and it matches my **branding**, so you have to change this file at your needs.

You can still use the same base for this file, but if you do so, **don't forget** to provide the proper attribution to the creator of this design.

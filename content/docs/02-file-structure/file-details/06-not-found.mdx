Considering the nature of how **Fumadocs** was built (aka, it was built on top of **NextJs**, it's then expected that any internal application broken routes would display a "Not Found" page).

In order to customize this file, **it's possible** to create as many **not-found.tsx / not-found.jsx** files as needed according to [NextJs official documentation](https://nextjs.org/docs/app/api-reference/file-conventions/not-found).

In this template, only the **global not-found** file was created, and the actual codebase of the file is part of what **I** use on my documentation templates and it matches my **branding**, so you have to change this file at your needs.

You can still use the same base for this file, but if you do so, **don't forget** to provide the proper attribution to the creator of this design.

Again, just like in the case of the landing page:

> Your creativity is the limit when working with this page!
